# MV Cut - Send to X (크롬 확장)

라이브러리 상세 화면의 "Send to X"를 누르면, X 새 글 작성 창을 열어 본문을 채우고 영상(또는 이미지)을 첨부한 상태까지 만들어 둡니다. 게시 버튼은 직접 누릅니다.

## 설치

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭
4. 이 폴더(`ServerCode/extension`)를 선택

설치 후 MV Cut 페이지를 새로고침하면 "Send to X"가 확장을 통해 동작합니다. 확장이 없으면 본문만 채운 작성 창을 열고 파일은 내려받습니다.

## 동작

1. 페이지가 서버에서 30분짜리 서명 링크(`/share/{id}/{만료}/{서명}`)를 발급받아 확장에 넘깁니다.
2. 확장이 `x.com/compose/post` 탭을 열고, 그 탭에서 서명 링크로 파일을 내려받습니다.
   서버가 이 링크에만 `Access-Control-Allow-Origin: https://x.com`을 붙여 주므로 세션 쿠키 없이 읽힙니다.
3. 작성 창의 텍스트 영역에 본문을 넣고, 파일 input에 파일을 넣습니다.

## 한계

- X가 DOM 구조를 바꾸면 선택자(`div[data-testid^="tweetTextarea_"]`, `input[data-testid="fileInput"]`)를 고쳐야 합니다.
- 서명 링크는 30분 뒤 만료됩니다. 그 전에 작성 창이 열려 파일을 받습니다.
- X의 업로드 제한(영상 길이·용량)을 넘는 파일은 작성 창에서 거부됩니다.
